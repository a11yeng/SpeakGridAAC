# FG AAC

A free, iOS-compatible AAC-style web app with the requested FG AAC default sample board.

## Default board

- Board name: FG AAC
- Default profile: Default
- Home page: Home
- Selection mode: Speak on first touch
- Message window: Off
- Voice speed: 1.0

## Home page

Home is 3 columns x 3 rows and includes: Yes, No, Pain, Stop, Food, Bathroom, Activities, and Keyboard, plus one blank placeholder.

Food, Bathroom, Activities, and Keyboard are speak-and-open-folder buttons.

## Folders

- Food: 3 columns x 3 rows with Pouch, Water, Ice, and blank placeholders.
- Bathroom: 3 columns x 3 rows with Pee, Poop, and blank placeholders.
- Activities: 3 columns x 3 rows with TV, Tablet, and blank placeholders.
- Keyboard: 10 columns x 3 rows with QWERTY letters, HOME, SOMETHING ELSE, and blank placeholders.

## Local-only storage

Profiles, boards, uploaded images, and passcodes are stored locally in the browser. They do not sync across devices unless you use the app's export/import profile feature.

## Hosting

Upload the contents of this folder to the root of a GitHub Pages or AWS Amplify static site.
